## Method Notes

- Static `src` graph handles relative `import`, `export ... from`, dynamic string `import()`, and string `require()`. `.js` import specifiers are normalized to `.ts`/`.tsx` source files.
- App roots are relative imports from `app/**/*.{ts,tsx,js,jsx}` into `src/`, followed through `src` imports.
- Replacement evidence comes from `testdata/contracts/v1/ENFORCEMENT_AUDIT.md` rows with `PROVEN-FAILS`, plus each corpus `source`/`sources` fields and the generated capture script source roots.
- Production files reached only through a capture script root are treated as replacement-evidenced by that capture corpus. Direct Vitest source metadata alone does not create broad production-file proof through arbitrary test imports.
- A survivor-closure pass reclassifies candidate DELETE files to UNSURE when a KEEP or UNSURE source file imports them, so the stated cut does not leave surviving `src` files with broken relative imports.
