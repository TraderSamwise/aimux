Loop overseer lifecycle v2

The overseer is explicit per-project state. A project can want an overseer, have a live overseer session, and assign agents to that loop. Those are visible model fields, not hidden prompt context.

Product rule: no automatic overseer row on the dashboard. Status appears only when enabled, errored, or explicitly opened. Press O to open the project overseer surface.
